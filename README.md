# FilterUsersBot
### Telegram и MAX бот для фильтрации логинов (например: k3jHj0ja1YEjxkauHzK)

## Что делает:
После отправки команды `/start` появляются Inline-кнопки:

<img width="272" height="262" alt="image" src="https://github.com/user-attachments/assets/4abe69c7-9754-46d5-b495-33aec05e36b8" />

- **Перемешать:** перемешивает содержимое файла  
- **Удалить дубликаты:** удаляет дублирующиеся строки  
- **Запомнить логины:** сохранят содержимо файла в SQLite БД  
- **Создать логины:** генерирует `.txt` файл со 100 случайными логинами длиной от 8 до 20 (цифры + английские буквы)

После выбора кнопки загрузите ваш `.txt` файл, за исключеним кнопки `Создать логины`

## Использование:
1) Введите ваш токен в `token=` (Bot.py)
2) Загрузите код на сервер (Локальный/VPS/VDS)
**Всё готово**
